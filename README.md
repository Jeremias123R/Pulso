# Pulso — Dashboard de Estudios de Neurodiagnóstico

Aplicación web para visualizar y analizar datos ficticios de estudios de neurodiagnóstico mediante indicadores, filtros y gráficos interactivos.

**Ver demo:** https://jeremias123r.github.io/Pulso/

## Qué hace

- Dashboard de análisis de estudios de neurodiagnóstico.
- Visualización de estudios de **EEG, EMG y Potenciales Evocados**.
- Indicador de cantidad total de estudios.
- Porcentaje de resultados alterados.
- Cálculo de edad promedio.
- Filtro por tipo de estudio.
- Filtro por lugar.
- Distribución de estudios por tipo.
- Evolución de estudios por mes.
- Comparación entre resultados normales y alterados.
- Análisis de los motivos de consulta más frecuentes.
- Distribución de estudios por rango de edad.
- Gráficos interactivos para facilitar la interpretación de los datos.

## Tecnologías

HTML, CSS y JavaScript · Chart.js · GitHub Pages

## Datos y privacidad

El dashboard utiliza datos 100% ficticios creados exclusivamente para demostración.

No contiene información real de pacientes ni datos clínicos identificables.
