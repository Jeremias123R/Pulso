Pulso — Dashboard de Estudios de Neurodiagnóstico

Dashboard web para analizar datos ficticios de estudios de neurodiagnóstico mediante indicadores, filtros y visualizaciones.

El proyecto está orientado al análisis de estudios como EEG, EMG y Potenciales Evocados, permitiendo observar diferentes aspectos de la información registrada.

«Proyecto ficticio de demostración. No utiliza información real de pacientes y no está destinado a uso médico real.»

📊 Qué hace

Pulso permite explorar información de estudios de neurodiagnóstico mediante una interfaz tipo dashboard.

Incluye:

- Estudios totales.
- Porcentaje de resultados alterados.
- Edad promedio de los estudios registrados.
- Filtro por tipo de estudio.
- Filtro por lugar.
- Distribución de estudios por tipo.
- Evolución de estudios por mes.
- Comparación entre resultados normales y alterados.
- Análisis de los motivos de consulta más frecuentes.
- Distribución de estudios por rango de edad.

🧠 Tipos de estudios

El dashboard trabaja con datos ficticios relacionados con:

- Electroencefalograma (EEG)
- Electromiografía (EMG)
- Potenciales Evocados

📈 Análisis

La información se presenta mediante diferentes indicadores y visualizaciones para facilitar la interpretación de los datos.

El dashboard permite observar:

- Qué tipos de estudios tienen mayor presencia.
- Cómo se distribuyen los estudios a lo largo del tiempo.
- Proporción de resultados normales y alterados.
- Motivos de consulta más frecuentes.
- Distribución de estudios según rango de edad.

🔎 Filtros

El sistema incorpora filtros para explorar los datos según:

- Tipo de estudio.
- Lugar.

Los indicadores y visualizaciones se actualizan de acuerdo con los datos seleccionados.

🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Chart.js

📱 Diseño

La interfaz está diseñada como un dashboard responsive, permitiendo consultar la información desde dispositivos móviles y computadoras.

El diseño está orientado a la visualización de datos y no a la gestión administrativa de una clínica.

🔒 Datos y privacidad

Todos los datos utilizados en este proyecto son ficticios.

No contiene información real de pacientes ni información clínica identificable.

El proyecto se presenta únicamente como una demostración de desarrollo web y visualización de datos.
